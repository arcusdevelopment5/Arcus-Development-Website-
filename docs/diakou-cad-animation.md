# Diakou floor-plan animation

Source: owner-supplied Πριν μετα.dwg (AutoCAD AC1032).
The previous manually approximated geometry is replaced by extracted CAD coordinates.
Before is the left plan; after is the right plan. Alignment subtracts (15.48643117, 0.52661855) from the after plan. Both use the same scale and rotation.
The exported geometry includes walls, openings and furniture; excludes text, hatch shading, construction-permit boundaries, remote stray objects and paper-space viewports.
209 identical aligned segments remain fixed. The other paths erase and draw with staggered timing. Curves are sampled from CAD arc, ellipse and bulge geometry.
LibreDWG reported warning code 68 during parsing. Both rendered plans were visually reviewed; this is a web presentation, not a replacement for the construction drawing. Only geometry is published, not the source DWG or its metadata.
The animation pauses outside the viewport, in a background tab, via local/global controls, and follows reduced-motion preferences. The original PDF-derived plan image links remain available.
